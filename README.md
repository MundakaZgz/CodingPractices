# Coding Practices

This repository is a personal practice space for improving my TypeScript and Python skills through daily coding exercises.

The goal is to build confidence, consistency, and problem-solving ability by working on small but meaningful challenges every day. Each exercise focuses on a different concept, from core logic and algorithms to testing, debugging, and clean implementation patterns.

## Purpose

I use this project to:

- strengthen my understanding of TypeScript
- improve Python problem solving and scripting skills
- practice clean, readable, maintainable code
- work with tests and edge cases
- build a habit of daily programming
- compare different approaches across languages

## Structure

The repository is organized by day or challenge. Each folder contains an exercise with its own implementation, tests, and notes when needed.

This approach keeps each task focused and manageable while allowing gradual improvement over time.

## Typical workflow

For each exercise, I usually:

1. read the problem carefully
2. design a solution
3. implement it in TypeScript or Python
4. validate with tests
5. debug edge cases
6. refactor for clarity and performance

## Skills being practiced

- arrays and data structures
- string and object manipulation
- algorithmic thinking
- time complexity analysis
- type safety in TypeScript
- Python fundamentals and idiomatic patterns
- testing and validation
- problem decomposition

## Philosophy

This repository is not about perfection on day one. It is about steady progress.

The focus is on learning by doing, staying consistent, and improving my technical foundation one exercise at a time.

## Notes

The exercises here are meant to be practical, incremental, and reusable as a training ground for everyday development skills.

Each day is an opportunity to learn something new, fix a bug, improve a solution, and become more confident in both TypeScript and Python.
